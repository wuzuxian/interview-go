# 02: DashScope ASR 实时协议客户端

**What to build:** 独立的语音识别（ASR）协议客户端（ADR 0003）：按运行时配置连 wss、完成会话更新（modalities=TEXT、server_vad、静音时长取配置）、持续推送 base64 音频帧、把服务端事件解析为回调（部分识别 / 最终识别 / 错误 / 连接关闭），支持 ready 检查、失效重启、多会话隔离。配套进程内假 DashScope 服务端夹具（可脚本化事件序列），供本票契约测试与后续管道测试复用。客户端不设接口接缝——URL 来自语音配置，测试打假端点。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 客户端可连配置指定的任意 ws:// / wss:// 地址；握手携带鉴权与运行时参数（URL/模型/语言/format/采样率/打断检测开关与阈值，来自语音配置源）
- [ ] 会话更新参数对齐：modalities=TEXT、server_vad 开、静音时长默认 2000ms（配置可覆盖）
- [ ] 事件解析覆盖：最终识别（含 transcript）、部分识别（text/delta 语义拼接）、error（脱敏后回调）、连接关闭；回调带会话归属
- [ ] ready 检查：建连后 10s 内未就绪视为失败，可重试至多 2 次（对齐 Java 常量）
- [ ] 失效重启：stop → 短歇（200ms）→ start → 1s 内 ready 验证；重启期间调用方送入的音频帧语义为失败可重发
- [ ] 多会话隔离：旧连接的迟到 onClose 不会清理新连接的状态（连接实例比对语义）
- [ ] 假 ASR 服务端夹具：可脚本化推送任意事件序列，支持延迟、乱序关闭、拒绝握手
- [ ] 契约测试驱动真客户端 × 假服务端（含 ready 超时、重启、事件解析），全程无外网
