# 3.关键运行时依赖

```
PostgreSQL(+pgvector) : 复用 Java 版 interview_guide 库与既有表结构(resumes/resume_analyses/llm_provider_config/llm_global_setting/vector_store/interview_sessions/interview_answers/voice_interview_sessions/voice_interview_messages/voice_interview_evaluations)
Redis                 : 异步任务 Stream——简历分析(resume:analyze:stream / analyze-group)、文字面试评估(interview:evaluate:stream / evaluate-group)与语音面试评估(voice:evaluate:stream / evaluate-group)共用同一套 Stream 消费/恢复基座形态(生产者置 PENDING+XADD、消费重试 3 次、恢复调度器补投)+ 接口限流
RustFS(S3)            : 简历原文件存储(bucket: interview-guide)
eino                  : cloudwego/eino + eino-ext openai ChatModel(JSON模式,含流式 Stream) / Embedding,按 DB 中 Provider 配置动态构建
密钥兼容              : Provider API Key AES-256-GCM 加解密与 Java 版互通,密钥来自 APP_APP_AI_API_KEY_ENCRYPTION_KEY
模块依赖(voiceinterview→) : interview(评估引擎 EvaluationRunner/评估 DTO/PromptSanitizer 与 AntiInjectionInstruction——evaluation.go、llm_prompt.go)、resume(Repo/ResumeEntity 简历文本进 prompt——llm_pipeline.go)、llmprovider(Service/AsrConfig/TtsConfig 语音配置源——settings_provider.go)、ai(StreamChatModel 流式模型接缝——llm_model.go)
```
